# Shape templates

Every named project shape (src/data/shapes.ts), to draw hand-drawn outlines over.

- Drawn at 2× the size they appear on a 1920×1200 screen (2.5× the design size), so 1 design px = 2.5 image px.
- Each shape has 16 design px (40 image px) of empty space on every side,
  so lines that go a little past the edge aren't cut off.
- The grey is the exact shape on the site, rounded corners included (8 design px).
