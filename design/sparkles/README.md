# Sparkles

Highlighted projects on the projects page get sparkles spaced all the way round their edge.
Each sparkle is a random pick from the PNGs in this folder: add, remove or replace them freely
(any file name, any number of them).

- Draw each one **pointing straight up**. The bottom of the image is the end nearest the shape,
  and the page turns each sparkle to point straight out from the edge.
- Same scale as the shape templates: **2.5 image px per design px**. A sparkle 15 × 29 px
  shows about 6 × 12 design px (before a little random resizing).
- Transparent background, cropped close: the image's bottom edge sits just outside the shape.

How far apart they are and how far from the edge they start: `SPARKLE_SPACING` and `SPARKLE_GAP`
in src/components/ProjectPile.astro.

sparkle-1.png to sparkle-3.png are plain placeholders, to be replaced with hand-drawn ones.
